# AppProxy

Проксификатор для Windows 10/11 x64. Интерфейс написан на C# с Windows Forms и .NET 10. Маршрутизацией через виртуальный адаптер TUN занимается отдельный процесс [sing-box 1.14.4](https://github.com/SagerNet/sing-box/tree/v1.14.4).

## Скачать и запустить

1. Скачайте `AppProxy-win-x64.zip` из [Releases](https://github.com/Ambrozy/proxy-win/releases).
2. Распакуйте весь архив и запустите `AppProxy.exe`. Подтвердите запрос Windows на запуск от имени администратора.
3. Нажмите **Из списка…**, найдите программы по названию или имени EXE. Чтобы выбрать несколько, удерживайте Ctrl или Shift, затем нажмите **Добавить**. Список строится по ярлыкам меню «Пуск» и путям программ, зарегистрированным в Windows. Если нужной программы нет, нажмите **Файлы…** и выберите её `.exe`. Файлы из разных папок можно добавить за несколько приёмов.
4. Вставьте `socks5://логин:пароль@сервер:порт` в поле **Ссылка SOCKS5** и нажмите **Применить** или **Включить**. Для IPv6 заключите адрес в квадратные скобки. Спецсимволы в логине и пароле кодируйте по правилам URL, например `%40` для `@`. Можно также заполнить поля вручную.
5. Нажмите **Включить**. Когда маршрутизация запустится, перезапустите выбранные приложения. Все выбранные EXE используют один прокси. Для отключения нажмите **Остановить**.

SOCKS5 передаёт TCP и UDP при поддержке `UDP ASSOCIATE` сервером. HTTPS CONNECT передаёт TCP и блокирует UDP для распознанного приложения. Правило сопоставляет полный путь `.exe`. Другие процессы, системный DNS от имени службы Windows и трафик вне TUN могут идти напрямую. Приложение не гарантирует блокировку всех прямых соединений.

## Сохранение настроек

При включении маршрутизации и закрытии окна AppProxy сохраняет поля и список программ в `AppProxy.settings.json` рядом с `AppProxy.exe` и читает файл при следующем запуске. Для записи нужна доступная на запись папка. Пароль и ещё не применённая ссылка SOCKS5 защищены Windows DPAPI для текущего пользователя. Если перенести файл на другой компьютер или открыть приложение под другой учётной записью Windows, пароль может потребоваться ввести заново. Маршрутизация включается кнопкой **Включить**.

## Если IPv4-прокси отклоняет IPv6-подключения

Включите **Только IPv4 в DNS через AppProxy**, остановите и снова запустите маршрутизацию, если она уже была включена. С включённой маршрутизацией выполните `ipconfig /flushdns` и полностью перезапустите браузер. На DNS-запросы AAAA, которые обрабатывает AppProxy, движок отвечает пустым результатом. Опция действует на DNS всех программ, запросы которых попали в AppProxy. Она не меняет настройки сетевых адаптеров и не фильтрует собственный DNS-over-HTTPS браузера или уже известные приложению IPv6-адреса. При проверке временно отключите Secure DNS в браузере, если он настроен на отдельного провайдера.

## Собрать из исходников

Потребуется .NET 10 SDK.

```powershell
dotnet publish AppProxy.csproj -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -o publish
```

Скачайте оригинальную сборку [sing-box 1.14.4 для Windows x64](https://github.com/SagerNet/sing-box/releases/tag/v1.14.4) и распакуйте её файлы в `publish/engine/`. Убедитесь, что файл движка находится по пути `publish/engine/sing-box.exe`. Запустите `publish/AppProxy.exe`.

Исходный код поставляемой версии движка доступен в [официальном репозитории sing-box](https://github.com/SagerNet/sing-box/tree/v1.14.4).
